## 关键实现点

| 环节 | 规则 |
|:---|:---|
| 门店选择 | `pickStore()`：`storeCode` 精确 → 关键词 → 最近 |
| 规格 | `query-meal-detail` 的 `rounds[].choices[]`，`code` 用于回传，`diffPrice` 用于展示差价 |
| 特调 | `supportModify=true` 标注【可特调】；`modification.values[]` 选中用 `selectedKey`，未选中且 `unselectedKey` 非空也**必须传** |
| 金额 | `calculate-price` 返回**分**，展示除以 100 |
| 自提 | `orderType=1` 时 `takeWayCode` 必传，取自 `takeWayList[].code` |
| beCode | 到店自取**禁止传** |
