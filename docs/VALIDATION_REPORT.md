| 类别 | 漏网产品 |
|:---|:---|
| 裹粉炸鸡 | 麦乐鸡、麦辣鸡翅、薄皮焦香V翅、那么大鸡排、麦麦脆汁鸡、蘸酱脆皮鸡柳、蘸酱炸鸡 |
| 面包胚（名称无「堡」） | **巨无霸**、麦香鱼、麦香鸡 |
| 饼干 / 蛋卷筒 | 麦当劳素龙限定饼干、圆筒冰淇淋、灰焰圆筒 |
| 薯制品口径不一致 | 扭扭薯（薯条杀、扭扭薯放） |

## 4. 关键实测结论（文档未写、但会直接导致失败的点）

| 约定 | 实际情况 |
|:---|:---|
| `currentPrice` | 字符串「**元**」（`"33.5"`）；`calculate-price` 是整数「**分**」；`diffPrice` 是 `"+ ¥0"`（**符号与 ¥ 之间有空格**） |
| `categories[]` | **没有 code 字段**，只有含换行的 name |
| `list-nutrition-foods.data` | **不是 JSON 数组**，是紧凑表格文本，真实表头 **9 列**（含 `nutritionDescription`、`energyKj`） |
| 售罄 | 菜单 `data.meals` 里不存在该 code；算价传错码返回 `60006` |
| `60006` 三种成因 | 售罄 / `orderType+beType` 不匹配 / **不在当前预约时段菜单** |
| `60001` | 该 code 在当前时段不售（正餐 code 在早餐时段） |
| `600050` | 收藏餐厅列表为空 —— 是**降级信号不是错误** |
| 接口不校验日期 | 传超出「今天+明天」的日期照样 200，只拦「过去时间」（`600053`） |
| `takeWayList` | 因店而异，实测至少 4 种：`eat-in` / `take-in-store` / `locker-in` / `locker-out` |
| `query-meals` 名称 | **普遍缺规格**（抽样 6/6 缺），价格不受影响但份量预期会错 |
